# 📊 Profit Dashboard (Profit Analyzer)

A modern and interactive **Profit Analyzer Web App** that helps users track income, expenses, savings goals, and financial insights with visual charts and downloadable reports.

---

## 🚀 Features

- 💰 Income & Expense Tracking  
- 📈 Profit Calculation (Total + Average)  
- 🎯 Savings Goal Tracker with Progress Bar  
- 📊 Interactive Charts (Chart.js)  
  - Profit Trend  
  - Expense Categories  
- 📅 Monthly Spending Calendar  
- 📜 Transaction History with Filter & Search  
- 🔍 Category-based Filtering  
- 🌙 Dark / Light Mode Toggle  
- 📥 Download Reports  
  - PDF Report  
  - Excel Report  
- ⚡ Real-time Financial Insights  
- 🔔 Notifications & Budget Alerts  

---

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Libraries Used:
  - Chart.js (for graphs)
  - jsPDF (for PDF export)
  - SheetJS / XLSX (for Excel export)
  - Font Awesome (icons)
  - Google Fonts (Poppins)
